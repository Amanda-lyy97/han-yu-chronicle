# 韩昌黎 · 行迹与文心

**在线访问**：https://ewmg5f0wfo.brewpage.app/ （BrewPage 免费匿名托管，当前有效期 30 天）

一个按时间轴阅读韩愈的静态网站：把韩愈的求学、仕宦、贬谪与写作放回中唐的政局与文坛现场。

## 打开方式

直接双击 `index.html` 即可。全站为纯静态文件，不需要安装依赖或启动服务器；使用系统自带的中文宋体/楷体，离线也能正常显示。

## 内容结构

- **总览**：韩愈生平与“读韩文”的五个入口。
- **求学与仕途**：七岁开卷、十三能文、十八入长安、四试进士、三试宏词、两入幕府；附“从八品到正四品”的仕途刻度，逐年标出品级与“相当于今天什么官”。
- **人生时间轴**：23 个节点，逐年标注地点、年龄、官职、求学/行事、唐史背景与系年文章。
- **行迹地图**：河阳、韶州、宣城、长安、汴州、徐州、洛阳、阳山、江陵、潮州、袁州、镇州、蓝关；四条行迹路线可开关。
- **文章库**：25 篇文章，可按时期、背诵要求筛选，也可检索篇名、人物、地点与关键词；每篇标出“文眼”并附一句解释。
- **唐史背景**：安史之乱、贞元困局、永贞革新、元和中兴、长庆余晖、文化与文统；附五位皇帝与韩愈的关系。
- **背诵篇目**：只按讲稿原话，区分“讲稿必背”与“可背”。
- **阅读方法**：每篇均按“为什么写—写了什么—怎样写”三段拆解。

## 背诵标注

只按卢麒元《韩昌黎文集》二十四讲中的原话标注，不采用高中课标必背篇目：

- **讲稿明确要求背诵（7 篇）**：《进学解》《送李愿归盘谷序》《送穷文》《祭十二郎文》《师说》《答李翊书》《马说》（《杂说四首》其四）。
- **讲稿说“可以尝试/可以背”（2 篇）**：《原道》《伯夷颂》。
- **讲稿明确说不必背**：《争臣论》《柳子厚墓志铭》《五箴》。

网站中的“讲稿必背”“可背”标记均据此而来；讲稿为讲课整理稿，若与原书或校本要求不同，以原书与课堂要求为准。

## 系年说明

系年以《旧唐书》《新唐书》本传、洪兴祖《韩子年谱》及通行为准。部分篇目学界有异说，凡不能确考者标“约”，并在“阅读方法”一节说明。例如《原道》《原毁》有五原作于阳山、作于贞元十九年长安、作于元和八年以后等说；《讳辩》有元和五年、六年等说；《伯夷颂》约在贞元末。

年龄按公元年份减 768 计（周岁），故 803 年为 35 岁，与讲稿一致；824 年卒为 56 周岁，传统虚岁作 57 岁。卒年从史传作 824 年。
